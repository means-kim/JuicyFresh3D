SENGRAPHICUS — MOVEMENT VFX PACK 01
Dust Start 01 / Poussière de démarrage 01

FRANÇAIS
========
Contenu :
- 12 images PNG RGBA transparentes, 512 x 512 px
- 1 sprite sheet compacte 4 colonnes x 3 lignes, 2048 x 1536 px
- 1 sprite sheet avec marge transparente de 8 px, 2112 x 1584 px
- 1 vidéo ProRes 4444 avec canal Alpha
- 1 aperçu MP4 sur fond sombre
- Visuels de présentation Itch.io

Réglages recommandés dans un moteur de jeu :
- Lecture : une seule fois (non bouclée)
- Vitesse : 12 images par seconde
- Ordre : gauche vers droite, puis ligne suivante
- Grille de la sprite sheet : 4 colonnes x 3 lignes
- Taille d’une cellule : 512 x 512 px
- Feuille avec marge : cellules de 528 x 528 px (image 512 x 512 centrée + 8 px de chaque côté)
- Utilisez la feuille avec marge si le filtrage bilinéaire ou les mipmaps créent un débordement entre les images
- Point d’ancrage conseillé : centre-bas
- Désactiver ou supprimer l’objet lorsque l’animation se termine

Usage : départ de course, dash, dérapage, atterrissage, choc au sol ou véhicule.

ENGLISH
=======
Contents:
- 12 transparent RGBA PNG frames, 512 x 512 px
- 1 compact transparent 4-column x 3-row sprite sheet, 2048 x 1536 px
- 1 sprite sheet with 8 px transparent padding, 2112 x 1584 px
- 1 ProRes 4444 video with Alpha channel
- 1 MP4 preview on a dark background
- Itch.io presentation artwork

Recommended game-engine settings:
- Playback: play once (non-looping)
- Speed: 12 frames per second
- Order: left to right, then the next row
- Sprite-sheet grid: 4 columns x 3 rows
- Cell size: 512 x 512 px
- Padded-sheet cell size: 528 x 528 px (512 x 512 image centered with 8 px on every side)
- Use the padded sheet when bilinear filtering or mipmaps cause neighbouring-frame bleeding
- Suggested pivot: bottom-center
- Disable or destroy the object when playback ends

Uses: running start, dash, skid, landing, ground impact or vehicle movement.
